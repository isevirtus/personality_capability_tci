# Supplementary Material S1 — Full-Entry Regression Models

Table S1 reports multiple regression models in which all ten predictors were entered simultaneously for each of the five perceived team-climate outcomes (`n = 148`). This unselected specification was estimated as a sensitivity analysis to examine whether the coefficients retained in the primary manual stepwise models remained detectable when every predictor competed for unique variance in the same model. Standardized coefficients and coefficient-level *p*-values are reported together with overall model fit.

The omnibus *F* test was statistically significant for Team Vision (*p* < .001) and IPTC (*p* = .014), but not for Support for Innovation (*p* = .051), Task Orientation (*p* = .060), or Participative Safety (*p* = .076). The latter coefficient-level results should therefore be interpreted cautiously and as part of a sensitivity analysis rather than as independently confirmatory models.

Every coefficient retained in the primary manual stepwise models remained statistically significant in the corresponding full-entry model: Responsibility for Team Vision (β = .308, *p* = .002) and Agreeableness for Task Orientation (β = .214, *p* = .026), Support for Innovation (β = .305, *p* = .002), Participative Safety (β = .287, *p* = .003), and IPTC (β = .299, *p* = .002). The full Team Vision model additionally identified Agreeableness (β = .246, *p* = .006), Openness (β = −.254, *p* = .003), and Teamwork Orientation (β = −.270, *p* = .029). These additional coefficients were not retained by the primary procedure and should not be described as primary-model predictors.

Bootstrap resampling provides a separate assessment of sensitivity to sampling variation. Responsibility was significant in 84% of the full-model bootstrap samples for Team Vision. Agreeableness was significant in 61% for Task Orientation, 87% for Support for Innovation, 88% for Participative Safety, and 89% for IPTC. The Task Orientation coefficient was consequently less stable than the other retained coefficients.
